# A12-03 Content Brief

A brief is structured fields, not a giant prompt.

Required: purpose, audience, topic, primary message, CTA, channel. Optional: angle, supporting facts, allowed claims, source refs, format, risk hint. Policy id/version stored on insert.

Audit: `content.brief_created`.

E2 default source: `DTH_APPROVED_EDUCATION_V1`. Volatile commercial claims cannot be sourced from model memory.
