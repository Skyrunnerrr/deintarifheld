# A4-15 A5 Handoff Contract

When A3 reevaluation reaches `QUALIFIED_FOR_CALL`:

- missing-info follow-ups cancelled (`CANCELLED_QUALIFIED`)
- conversation status `QUALIFIED`
- A1 job `APPOINTMENT_OFFER_PREPARE` enqueued (placeholder)
- no calendar provider call
- no appointment email

A5 owns slot search, offer send, booking, reminders.

A6 owns document/OCR if `attachment_count > 0` (`A6_DOCUMENT_HANDOFF_REQUIRED` contract only).
