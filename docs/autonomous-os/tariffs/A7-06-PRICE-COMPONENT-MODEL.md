# A7-06 Price Component Model

Supported types: ENERGY_VARIABLE, BASE_FIXED, METER_FIXED, SITE_FIXED, BONUS, DISCOUNT, SURCHARGE, TAX_COMPONENT, OTHER_FIXED, OTHER_VARIABLE.

Frequencies: PER_KWH, PER_YEAR, PER_MONTH, PER_DAY, ONE_TIME. `applies_to`: first_year|ongoing|both. `per_supply_point` multiplies fixed/one-time amounts.
