# ADR-021 — Database Role and Credential Boundary

STATUS=ACCEPTED
TRANCHE=DTH-M10
DATE=2026-08-13
M10_DEPENDENCY_NOTE=Exact GRANT lists in M11

## Context
M9F froze DTH-ERA-A Evolutionary Dual-Plane at `0702fab`. M10 decides data topology, SoT, credentials/grants/RLS layers, and persistence classes. Implementation (SQL/roles/policies) is deferred to M11+.

## Binding facts (not optional)
- Supabase `service_role` / privileged secret keys operate with `BYPASSRLS` — RLS does not protect that path.
- PostgreSQL GRANTs and RLS are separate controls: grants gate object access; RLS filters rows for roles that do not bypass RLS.

## Decision
Target DB principals: PUBLIC_INTAKE (narrow insert), OPS_API, WORKER, MIGRATION_RUNNER, AUDIT_WRITER; optional READ_ONLY_SUPPORT / RECONCILIATION_JOB. CC and Agent have NO direct DB roles. Default BYPASSRLS=NO. Any BYPASSRLS principal requires explicit exception. Current broad service_role is NOT target.

## Rejected options
service_role as permanent normal public path; agent/CC direct DB; shared admin role for all runtimes.

## Security impact
Least-privilege DB principals; no general-purpose service_role as normal runtime target; defense in depth (App AuthZ + grants + RLS).

## Privacy impact
Data minimization in queues/audit/traces; staging without production PII; deletion/lineage traceable.

## Operations impact
Postgres-first; single migration authority; evolutionary cutover; no big-bang rewrite of live public intake.

## Migration impact
Additive structures first; public intake remains stable; Ops/local migrations reconciled under one authority.

## Rollback
Architecture docs only in M10. Implementation rollback plans live in migration strategy (CURRENT→TRANSITION→TARGET).

## Dependencies
M9F architecture contract; existing `supabase/migrations` 001–013; packages/db drafts DO_NOT_APPLY.

## Open questions
Exact SQL DDL, policy expressions, retention durations (legal review), environment apply order — M11+/legal.

## M10R HARDENING
Role assumption = DIRECT_POSTGRES_LOGIN_ROLE. service_role Data API is not target PUBLIC_INTAKE. Runtime roles must not own protected tables.

## M10F FREEZE
Frozen with DTH-M10F. Architecture ACCEPTED; implementation remains NOT_IMPLEMENTED until authorized tranches.
